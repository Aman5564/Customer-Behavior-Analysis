# Customer-Behavior-Analysis
Data Analytics projects showcasing Customer Behavior Analysis using Python, MySQL, Power BI.
Customer Behavior Analysis | Data Analytics Project
Overview

This project analyzes customer shopping behavior for a retail company to uncover purchasing trends, customer preferences, and key factors influencing buying decisions. The goal is to help the business improve customer engagement, optimize marketing strategies, increase sales, and build long-term customer loyalty.

The project follows a complete Data Analytics workflow using Python, MySQL, and Power BI, transforming raw customer transaction data into actionable business insights.

Business Problem

A retail company observed changing customer purchasing patterns across demographics, product categories, and sales channels. The company wanted to understand:

What factors drive customer purchases?
Which customer segments generate the most revenue?
How do discounts influence spending behavior?
Are subscribed customers more valuable?
Which products and categories perform best?
How can customer engagement and marketing strategies be improved?

Project Workflow
1. Data Preparation (Python)
Loaded and inspected the raw dataset.
Checked data quality and missing values.
Filled missing Review Ratings using category-wise median values.
Standardized column names.
Created customer Age Groups for segmentation.
Prepared clean data for analysis.
2. Exploratory Data Analysis (EDA)

Analyzed:
